# Finished slide images

69 lossless WebP images at 1280 × 720, exported on 16 October 2026.

Each image shows a slide's final state with all click reveals visible. Intermediate build steps are omitted, so the consecutive image numbers differ from Reveal's browser slide numbers.

The six video slides use frames from two seconds into each video. Speaker notes, playback controls and transitions are excluded.

These images are snapshots; slide edits do not update them automatically.
